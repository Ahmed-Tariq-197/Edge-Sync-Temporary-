📋 Section 3: Protocol Message Data Dictionary (CDR Binary Mapped)
ROS 2 Message Interface Field Name Data Type Physical Units / Value Range Architectural Role & Description
HeaderCommon protocol_version uint16 0x0203 (v2.3) Compatibility gating; mismatched protocol versions rejected immediately.
transaction_id string UUID / String token Explicit separation of handoff transaction from physical target_id.
ownership_epoch uint64 Monotonic counter Single ownership invariant enforcement; stale epochs rejected (FR-54).
stamp_utc_ns int64 Nanoseconds UTC PTP IEEE 1588v2 timestamp for staleness and deadline validation.
HandoffRequest.msg tto_deadline_utc_ns int64 Absolute UTC nanoseconds Calculated deadline at which target tracking will fail on Robot A.
tto_remaining_ms_at_send int32 Milliseconds (1230–2500 ms) Relative deadline fallback when clock offset exceeds budget δ_sync.
position / velocity float32[3] Meters / (Meters/sec) Target 3D position and velocity expressed in shared frame_id = "map".
cov_upper_triangle float32[21] Meters² covariance Symmetric 6x6 upper-triangle target state covariance.
reid_feature_vector float32[512] Unit L2-norm vector 2048-byte OSNet embedding for cross-robot visual verification.
HandoffResponse.msg decision uint8 1=ACCEPT, 2=REJECT, 3=UNAVAIL Outcome of receiver hard gate G(j) and analytical feasibility check.
est_acquisition_ms int32 Milliseconds (≤ 700 ms) Receiver estimated slew and target lock latency.
AcqStatus.msg (10 Hz) status uint8 1=SLEWING, 2=SEARCHING, 3=ACQUIRED Anti-deadlock heartbeat payload; 3 missed trips watchdog (300 ms).
HandoffConfirm.msg reid_similarity float32 Cosine similarity [0.0, 1.0] Verification score (must satisfy threshold ≥ 0.70 to confirm).
HandoffConfirmAck.msg new_epoch uint64 epoch e + 1 Owner release confirmation; activates ownership on Robot B (FR-54).
